# Language Daily Bot

Sends a daily language-learning lesson to a Telegram channel, generated by
Claude Haiku — built for **relearning** after a long gap, not learning from
zero. The main focus is reactivating everyday **German (A2/B1)**, but you can
also feed the bot your own words in **German, Italian, English, or Japanese**
and they get taught first.

Each day: up to **5 words** — your queued words first (each taught in its own
language), then auto-generated German to fill the rest (easiest first:
`A2, A2, B1, B1, B2`) — plus **2 words due for spaced-repetition review**
(1 → 3 → 7 → 16 → 35 → 90 day intervals), a rotating **German grammar tip**
from a 20-topic B1 curriculum, and **one voice note per language** present that
day (headwords + example sentences read aloud). Glosses are in English only.

## Add your own words (Telegram)
DM the bot the words you want to learn — it reads them on its next run, queues
them, and confirms by DM. Tag the language (untagged defaults to German;
Japanese script is auto-detected):

```
it: frigorifero, lavatrice
ja: 冷蔵庫
en: reliable
der Kühlschrank        ← untagged = German (a leading article is stripped)
```

Your queued words are taught **first**, in the order you added them, until the
queue empties. Commands: `/list` (show your queue), `/help`.

**Only one Telegram account can add words** — the bot silently ignores everyone
except `ALLOWED_USER_ID` (set in `language_daily_bot.py`, overridable via the
`TELEGRAM_ALLOWED_USER_ID` env/secret). Lessons post to the channel in
`TELEGRAM_CHAT_ID`; word-adding happens in your private DM with the bot, so make
sure you've pressed **Start** on the bot once.

## Focus / toggles
- **German-focused, Turkish off.** Turkish output is disabled via
  `INCLUDE_TURKISH = False` in `language_daily_bot.py` — flip it back to `True`
  to restore Turkish translations everywhere.
- Change the daily size/mix with `WORDS_PER_DAY` and `GERMAN_AUTO_SLOTS`.

## Voice notes (Microsoft Edge TTS)
Voice is generated with [`edge-tts`](https://github.com/rany2/edge-tts) (free,
same TTS service as Microsoft Edge's Read Aloud), then converted to ogg/opus
with `ffmpeg` (required on PATH) so Telegram delivers proper voice-note bubbles.
One note is sent per language present that day, each with its matching neural
voice (see `VOICES`). Only target-language text is spoken — English is never
sent to TTS. Toggle everything with `ENABLE_VOICE`.

## Run locally
```bash
pip3 install -r requirements.txt
brew install ffmpeg              # or your OS's package manager
cp .env.example .env            # then fill in your real values
python3 language_daily_bot.py --dry-run   # build a sample lesson, print it, send nothing
python3 language_daily_bot.py --once      # generate + send for real
```

## Run automatically (GitHub Actions)
Daily run is handled by `.github/workflows/language-daily.yml` (06:00 UTC).
The **Run workflow** button also ingests any words you've DM'd, on demand.
Credentials come from repository Secrets:
`TELEGRAM_BOT_TOKEN`, `TELEGRAM_CHAT_ID`, `ANTHROPIC_API_KEY`
(optional: `TELEGRAM_ALLOWED_USER_ID`).

`progress.json` stores each word's language + review schedule, the current
grammar topic, your pending word queue, and the Telegram update offset. The
workflow commits it back after every successful run — don't delete it once it
exists, or review scheduling, your queue, and message tracking reset.
