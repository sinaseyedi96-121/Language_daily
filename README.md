# Italian Daily Bot

Sends 10 new Italian words/expressions (A2/B1) to a Telegram channel every day,
generated by Claude Haiku — with English + German translations, three example
sentences each, and a short mini-review.

## Run locally
```bash
pip3 install -r requirements.txt
cp .env.example .env      # then fill in your real values
python3 italian_daily_bot.py --once
```

## Run automatically (GitHub Actions)
Daily run is handled by `.github/workflows/italian-daily.yml`.
Credentials come from repository Secrets:
`TELEGRAM_BOT_TOKEN`, `TELEGRAM_CHAT_ID`, `ANTHROPIC_API_KEY`.
